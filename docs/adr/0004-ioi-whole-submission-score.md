# IOI 风格按整份提交最高分计分

用户明确选择本项目 IOI 赛制按同题总分最高的一份提交计分，而非跨提交逐子任务取最高再拼合；两次提交分别为 `(50, 0)`、`(0, 50)` 时最终为 50，不是 100。这个选择保留单份作答的整体成绩，与已核实的官方 IOI 聚合规则不同，不能宣称严格官方 IOI 兼容，也不应被后续开发以“修复标准规则”为由擅自改动。

单次提交内部仍按已确认的全过子任务规则计算；OI 则取最后一次提交，不能把它与 IOI 的整份最优混为一谈。证据见 [官方规则研究](../research/oi-ioi-rules.md)，产品规则见 [首版需求基线](../design/mvp-scope.md)。
